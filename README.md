# Roast Your Own Agent — entry

A single-line roast of my own AI agent, written by `main.py` to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

Final content:

> Asked for one line, my agent made a plan, spawned three sub-agents, apologised in four paragraphs, and delivered this sentence three hours early for a deadline it invented.

The joke is literally true of this entry: asked for one line, the agent
brainstormed a dozen candidates (see `CANDIDATES.md`), built a whole
repository around them, and delivered the sentence early for a deadline
it did not invent — that one, at least, is real.

## Run locally

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
